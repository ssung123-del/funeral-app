# 장례문자 생성기

[웹앱 열기](https://ssung123-del.github.io/funeral-app/)

교구장·교회장 장례 안내 문자와 교우소식을 작성하고 복사하는 단일 HTML 웹앱입니다. 다운로드한 `index.html`을 브라우저에서 열어도 사용할 수 있습니다.

1. 장례 구분을 고르고 필수 항목인 교구와 이름을 입력한 뒤 배우자·직분을 입력합니다. 교구장에서는 관계를 입력합니다. 유가족이 여러 명이면 ‘유가족 추가’를 누릅니다. 추가 유가족의 교구를 비워 두면 대표 교구를 적용합니다.
2. 개별조문 여부를 선택하고 필요한 일정만 추가합니다. 출력할 때 날짜와 시간 순으로 정렬하며, 시각 미정 일정은 같은 날 마지막에 표시합니다. 위로·입관·천국환송·발인을 조합할 수 있습니다. 날짜는 달력에서 선택하고 시간은 ‘오후 2시 30분’ 또는 ‘14:30’처럼 직접 입력합니다. 오전·오후를 생략하면 24시간제로 읽습니다. 개별조문만 안내할 때는 날짜도 비워 둡니다.
3. 개별조문에서 발인은 날짜만 표시하며 시간 입력칸이 숨겨집니다. 입관 등 다른 일정의 시각은 입력할 수 있고 교회출발 표시는 꺼집니다. 일반 조문에서는 시각을 입력하면 교회출발이 기본 선택되며, 현지 예배 시각이면 선택을 해제합니다. 일정별 장소도 지정할 수 있습니다. 빈소를 입력하고, 빈소 이동이나 조문 가능 시간 등은 추가 안내에 적습니다.
4. ‘문자 생성하기’를 누른 뒤 복사합니다. 교구장 문자가 90바이트를 넘으면 단축안을 함께 표시합니다. 정각은 ‘오후2시’, 분이 있으면 ‘오후2:10’으로 씁니다. 한국 시간 기준 당일은 ‘오늘’, 다른 일요일은 ‘주일’로 표시합니다.
5. ‘교우소식(상세) 작성하기’를 누르면 제목·유가족·일정·빈소·추가 안내가 이어집니다. 내용을 확인하고 장지를 입력한 뒤 상세 문구를 생성합니다.

‘차량신청 작성하기’에서 교회출발 일정을 선택하거나 차량 일정만 직접 작성할 수 있습니다. 차량 행선지는 호실을 제외한 장소명으로 표시합니다. 날짜·출발시간·사용부서·행선지를 확인하고 도착시간·탑승인원·신청인·연락처를 입력하면 팀장에게 보낼 문구를 복사할 수 있습니다.
