# 장례문자 생성기

[웹앱 열기](https://ssung123-del.github.io/funeral-app/)

교구장·교회장 장례 안내 문자와 교우소식을 작성하고 복사하는 단일 HTML 웹앱입니다. 다운로드한 `index.html`을 브라우저에서 열어도 사용할 수 있습니다.

1. 장례 구분을 고르고 교구·이름·배우자·직분을 입력합니다. 교구장에서는 관계를 입력합니다. 유가족이 여러 명이면 ‘유가족 추가’를 누릅니다. 추가 유가족의 교구를 비워 두면 이름과 관계만 본문에 들어갑니다.
2. 개별조문 여부를 선택하고 필요한 일정만 순서대로 추가합니다. 위로·입관·천국환송·발인을 조합할 수 있습니다. 발인 날짜만 알면 시간은 비워 둡니다. 개별조문만 안내할 때는 날짜도 비워 둡니다.
3. 일정마다 교회출발 여부와 장소를 지정할 수 있습니다. 빈소를 입력하고, 빈소 이동이나 조문 가능 시간 등은 추가 안내에 적습니다.
4. ‘문자 생성하기’를 누른 뒤 복사합니다. 교구장 문자가 90바이트를 넘으면 단축안을 함께 표시합니다. 정각은 ‘오후2시’, 분이 있으면 ‘오후2:10’으로 씁니다. 한국 시간 기준 당일은 ‘오늘’, 다른 일요일은 ‘주일’로 표시합니다.
5. ‘교우소식(상세) 작성하기’를 누르면 제목·유가족·일정·빈소·추가 안내가 이어집니다. 내용을 확인하고 장지를 입력한 뒤 상세 문구를 생성합니다.
